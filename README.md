# Personal Portfolio Website

A minimal, responsive, and human-centric personal portfolio built to showcase my software engineering background, database design projects, and development work.

## Features
- **Clean UI & Navigation**: Simple, single-page layout designed with a neutral color palette and accessible typography.
- **Projects Showcase**: Interactive cards featuring directly linked GitHub repositories for my database and web projects.
- **Direct & Interactive Contact**: Built-in contact form along with direct links to my email, phone, LinkedIn, and GitHub profiles.

## Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Custom properties, CSS Grid/Flexbox, and responsive styling using the Inter font.
- **JavaScript (ES6)**: Lightweight DOM interactions and form handling.

## Deployment
Hosted live using **GitHub Pages**.
